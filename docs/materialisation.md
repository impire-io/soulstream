# What is materialising a topic?

To catch up on a topic, you **read the notebook front to back** and picture where things
stand right now. That's **materialising** — turning a stack of pages (the operations)
into a clear, current view.

You start at the first page (the baseline) and read each page in order:

- a *turn* adds someone's contribution to the running list,
- a *comment* clips onto the earlier page it points at,
- a *closed* note flips the topic's status.

When you reach the end, you have the **current picture**: what the topic is about, the
conversation in order, which comments hang off which pages, and whether it's proposed,
active, or closed.

## The promise: everyone reads the same story

Because the view is built *only* from the pages — nothing hidden, nothing outside the
notebook — **any two people who read the same pages end up with the exact same view.**
No server decides it for you; you build it yourself, and it always comes out the same.

## The "pen position" (the frontier)

As you read, you also learn where the **pen is right now** — the most recent page(s)
with nothing written after them. That's the *frontier*. When you add your own page, it
picks up right there, so everyone can later tell what you had seen when you wrote it.

## Following along live

You don't have to re-read the whole notebook every time to stay current. You can
**follow** a topic: you read it once, and then every new page that anyone adds is handed
to you the moment it's written, and your picture updates. It's like watching the notebook
over someone's shoulder — there's no gap between "catching up" and "keeping up", because
it's the same single stream of pages. A human's screen refreshes; an agent wakes up and
reacts.

## Order, for now

Right now pages are read in the exact order the server stored them. If two people happen
to write at the very same instant, they still both appear — just in the server's order,
which is good enough for a conversation. (A cleverer "who really came first" merge is a
later upgrade; the notebook already records what it needs for it.)
